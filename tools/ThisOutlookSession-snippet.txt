HUONG DAN DAN VAO ThisOutlookSession

ThisOutlookSession KHONG phai file .bas/.cls rieng - day la module CO SAN
trong moi VBA Project cua Outlook, nam trong nhanh "Microsoft Outlook
Objects" o Project Explorer. KHONG import file duoc, phai copy doan code
duoi day roi dan truc tiep vao code pane cua no.

CACH DAN:
1. VBA Editor (Alt+F11) > Project Explorer > mo rong "Microsoft Outlook
   Objects" > double-click "ThisOutlookSession".
2. Neu code pane da co san Application_Startup, chi THEM dong
   ResumeShrinkIfPending vao trong no (xem muc A ben duoi), khong tao
   Application_Startup thu hai - VBA chi cho phep 1 ham cung ten.
3. Neu code pane trong hoan toan, dan ca doan o muc A vao.
4. Debug > Compile VBAProject de kiem tra khong loi.
5. Luu VBA project (Ctrl+S trong Outlook, khong phai trong VBA Editor).

================================================================
A. DOAN CODE CAN CO
================================================================

Private Sub Application_Startup()
    Call Module2.StartArchiveAutoTimer
    Call Module1.ResumeShrinkIfPending
End Sub

================================================================

GHI CHU:

- "Module1" / "Module2" phai DUNG TEN module trong Project Explorer cua
  ban:
    Module1 = module chua CampaignTracker.bas (co SendCampaign,
              RecallCampaign, ShrinkNow)
    Module2 = module chua ArchiveModule.bas (co ArchiveNow)
  Neu ban dat ten khac luc import, doi lai cho khop.

- Tac dung cua ResumeShrinkIfPending: co che tu rut gon Sent Items (watcher
  ItemAdd + Windows Timer) chi song trong PHIEN Outlook hien tai. Neu dong
  hoac khoi dong lai Outlook GIUA MOT DOT GUI DAI (campaign lon co the mat
  vai tieng de Outlook truyen het Outbox), ca hai deu chet va tu do khong
  con gi rut gon nua - ban sao day du (co the ~4MB/mail) se chat dan Sent
  Items cho den khi DAY HOP THU, luc do Exchange CHAN gui va dot gui dut
  giua chung.
  Dong nay bat lai chung tu dong ngay o lan mo Outlook tiep theo, nen
  nguoi dung khong phai nho chay ShrinkNow bang tay nua.

- Ham nay tu thoat ngay neu Outbox khong con mail cho gui, tuc la khi
  Outlook khoi dong binh thuong thi no khong lam gi ca, khong ton tai
  nguyen va khong hien hop thoai nao.

- Neu vi ly do nao do Application_Startup khong chay (vd macro bi chan boi
  cai dat Trust Center), van co the chay macro ShrinkNow bang tay qua
  Alt+F8 - ket qua tuong duong, chi khac la co hien thong bao ket qua.
