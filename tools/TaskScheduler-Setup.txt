HUONG DAN DANG KY WINDOWS TASK SCHEDULER - chay ArchiveOldCampaignSentItems
moi 12 tieng/lan, khong can mo Outlook thu cong.

Dieu kien truoc (moi may/mailbox):
  1. Da import CampaignTracker.bas (co Sub ArchiveOldCampaignSentItems) vao
     VBA Project cua Outlook tren may do.
  2. Da sua MODULE_NAME trong tools/RunArchiveTask.vbs cho khop ten module
     thuc te (xem huong dan trong chinh file .vbs do).
  3. Da test thu cong file .vbs (double-click), kiem tra co dong log moi
     trong C:\SHBTrackerLogs\archive-log.txt.
  4. Outlook Macro Settings khong chan macro noi bo (File > Options > Trust
     Center > Trust Center Settings > Macro Settings).

Cac buoc dang ky Task Scheduler:
  1. Mo "Task Scheduler" (go tim trong Start Menu).
  2. Panel phai > "Create Task..." (KHONG dung "Create Basic Task" de co
     day du tuy chon o buoc 4).
  3. Tab General:
       - Name: SHB Archive Campaign Mail
       - Chon "Run whether user is logged on or not" NEU muon chay ca luc
         khoa may (can nhap mat khau Windows luc luu task). Neu chi can
         chay khi dang dang nhap, de mac dinh "Run only when user is
         logged on".
       - Tick "Run with highest privileges" (tranh loi quyen truy cap
         COM/Outlook).
  4. Tab Triggers > New...:
       - Begin the task: On a schedule
       - One time, chon ngay/gio bat dau bat ky (vd hom nay, 08:00).
       - Tick "Repeat task every:" chon "12 hours".
       - "for a duration of:" chon "Indefinitely".
       - OK.
  5. Tab Actions > New...:
       - Action: Start a program
       - Program/script: wscript.exe
       - Add arguments: "C:\duong-dan-toi\shb-dashboard-media\tools\RunArchiveTask.vbs"
         (thay dung duong dan thuc te tren may nay, giu nguyen dau ngoac kep)
       - OK.
  6. Tab Conditions: bo tick "Start the task only if the computer is on AC
     power" neu day la laptop hay chay bang pin (khong thi task se bi bo
     qua khi khong cam sac).
  7. Tab Settings: tick "Run task as soon as possible after a scheduled
     start is missed" (phong khi may tat dung luc den gio chay).
  8. OK, nhap mat khau Windows neu duoc hoi (do chon "Run whether user is
     logged on or not" o buoc 3).

Kiem tra hoat dong:
  - Trong Task Scheduler, chuot phai vao task vua tao > "Run" de chay thu
    ngay, khong can doi den gio.
  - Kiem tra tab "History" cua task (neu bat) hoac file log
    C:\SHBTrackerLogs\archive-log.txt de xac nhan da chay va chuyen duoc
    bao nhieu mail.

Cai dat tren may/mailbox khac:
  - Lap lai dung 4 buoc "Dieu kien truoc" o tren cho tung may/mailbox rieng
    (import .bas, sua MODULE_NAME trong .vbs, test tay, kiem tra Macro
    Settings), roi dang ky lai Task Scheduler tren may do voi duong dan
    file .vbs tren CHINH may do.
  - Neu ten store "Archives" / folder "Archive" tren may do khac ten mac
    dinh, sua ARCHIVE_STORE_NAME / ARCHIVE_FOLDER_NAME ngay trong
    CampaignTracker.bas cho khop (xem Data File Properties > Filename de
    xac nhan dung store, nhu da kiem tra truoc do).
